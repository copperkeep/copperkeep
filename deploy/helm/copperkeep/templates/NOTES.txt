Three things to check before handing this to a learner:

1. Cross-origin isolation. Open https://{{ .Values.ingress.host }}/#conformance and run
   the suite. If "crossOriginIsolated" is false, interrupt() cannot work and every
   infinite loop kills the worker instead. Something in front of the web service is
   stripping COOP/COEP — set ingress.crossOriginIsolationHeaders=true or fix the proxy.

2. TLS. {{ if .Values.ingress.tls.enabled }}Confirm the certificate resolves. A private IP over HTTP is not a
   secure context, so SharedArrayBuffer, service workers and storage.persist() all fail.{{ else }}ingress.tls.enabled is FALSE. SharedArrayBuffer, service workers and
   navigator.storage.persist() will not work. This is not a production configuration.{{ end }}
